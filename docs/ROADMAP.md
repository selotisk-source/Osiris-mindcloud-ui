# MindCloud / MindCore Roadmap

## P0 — Kernel
Typed task, agent, capability, evidence and promotion contracts.

## P1 — Execution
Living DAG, dependency resolution, routing, lifecycle, cancellation and recovery.

## P2 — Dirigentverket
Agent orchestration, parallel execution, dynamic task injection and workload balancing.

## P3 — Evidence + Metanoia
Evidence Passport, provenance, contradiction detection, alternative hypotheses, counterfactual/information-gain tests and versioned model changes.

## P4 — Capability ecosystem
Tool registry and adapters. Tools remain replaceable capabilities rather than hard-coded dependencies.

## P5 — Execution surfaces
Brave split-screen/multi-station workstation, APIs, research interfaces and other clients.

## P6 — Validation
OSIRIS and other concrete systems validate and improve the general platform.

## First acceptance criterion
MindCore can accept a typed task, build a dependency graph, route it to a declared capability, record evidence, verify the result, and safely accept or reject the resulting state transition.
